# Безпечна система управління обліковими записами

Лабораторна робота 6 з дисципліни «Безпека програм та даних».
Вебзастосунок для реєстрації та входу користувачів із захистом облікових записів.

## Можливості

- Реєстрація та вхід, політика пароля (довжина, великі й малі літери, цифра, символ), хешування паролів Argon2id
- CAPTCHA при реєстрації
- Активація облікового запису за посиланням з листа
- Захист від перебору паролів (тимчасове блокування після 5 невдалих спроб)
- Двофакторна автентифікація (TOTP — Google Authenticator та подібні)
- Вхід через зовнішнього провайдера (OpenID Connect)
- Відновлення пароля через email
- Ролі: користувач і адміністратор (перегляд користувачів, журнал входів, блокування акаунтів)

## Технології

Python 3, Flask (REST API), SQLite, HTML + CSS + JavaScript (без фреймворків).

## Що потрібно встановити

- [Python 3.10 або новіший](https://www.python.org/downloads/) (при встановленні на Windows відмітьте «Add Python to PATH»)

## Як запустити

1. Відкрийте термінал у папці `lab6` цього репозиторію.

2. Встановіть залежності:

   ```bash
   pip install -r requirements.txt
   ```

3. Запустіть застосунок.

   Windows (PowerShell):

   ```powershell
   $env:ADMIN_EMAIL="admin@example.com"; $env:ADMIN_PASSWORD="Admin!Pass1"; python run.py
   ```

   Linux / macOS:

   ```bash
   ADMIN_EMAIL=admin@example.com ADMIN_PASSWORD='Admin!Pass1' python run.py
   ```

4. Відкрийте у браузері <http://localhost:5000>.

Щоб зупинити застосунок, натисніть `Ctrl+C` у терміналі.

## Як користуватися

- **Реєстрація.** Натисніть «Реєстрація», заповніть форму та пройдіть CAPTCHA.
- **Листи.** Справжня пошта не потрібна: усі листи (активація, відновлення пароля) з'являються на сторінці **«Dev-пошта»** у верхньому меню застосунку. Відкрийте лист і перейдіть за посиланням.
- **Адміністратор.** Увійдіть з даними з кроку 3 (`admin@example.com` / `Admin!Pass1`) — з'явиться розділ «Адмін-панель».
- **2FA.** У «Профілі» натисніть «Увімкнути 2FA» і відскануйте QR-код додатком-автентифікатором.
- **Вхід через OpenID Connect.** Кнопка «Увійти через OpenID Connect» веде на демонстраційного провайдера, який запускається разом із застосунком (порт 5001).

## Налаштування (необов'язково)

Задаються змінними середовища:

| Змінна | Призначення | За замовчуванням |
|--------|-------------|------------------|
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | створити адміністратора при запуску | — |
| `MAX_FAILED_ATTEMPTS` | невдалих спроб до блокування | 5 |
| `LOCKOUT_SECONDS` | тривалість блокування, с | 300 |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD` | відправка реальних листів | вимкнено |
| `OIDC_ISSUER`, `OIDC_CLIENT_ID`, `OIDC_CLIENT_SECRET` | інший OpenID-провайдер, наприклад Google | демо-провайдер |
